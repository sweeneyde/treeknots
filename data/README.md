This `data` folder contains gzip-compressed text files listing the homfly polynomials resulting
from different tree-pairs.

The filenames have the form `treepairs(NUM)(o?)(p?)(m?)(r?).txt.gz`:
- The number `NUM` is the maximum number of leaves each tree can have.
- The flag `o` indicates that only tree-pairs with one-component links (knots) are listed.
- The flag `p` indicates that no tree-pair has an embedded subsquare
    (some proper nontrivial set of subset of the leaves supporting a
    subtree in either tree).
- The flag `m` indicates that the file was generated by grouping
    tree-pairs together with a set of known moves first, then only computing invariants
    for one tree-pair from each component.
- The flag `r` indicates that reflections were among the allowed moves.
